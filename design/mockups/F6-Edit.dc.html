How this works
Recipes live in a GitHub repository, not in this app.
If it's your repository: GitHub opens this recipe's file. Change it and tap Commit. A check runs and the site updates in about 2 minutes. A broken edit never goes live.
If it's someone else's: GitHub makes you a copy and sends them your change as a suggestion. They decide whether to accept it.
You need a free GitHub account.
